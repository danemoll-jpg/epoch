Epoch sound check

Tap Play on each sound. It plays at the loudness the game uses (every file is brought to the same level). A file that isn't there yet says missing. The list and file names are in docs/SOUNDS.md.

Music

The theme plays on the main menu and the New Game screen; in a game, the track for your era plays (crossfading when a new era begins), and the theme stands in for any era track that's missing. Each track loops. Play plays 20 seconds (tap again to stop).
